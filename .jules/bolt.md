## 2024-06-02 - Bolt: Prevented cache corruption and optimized array transformations
**Learning:** Arrays returned by `store.getAll()` are direct references to the in-memory cache. Mutating them directly (e.g., using `.sort()`) corrupts the cache across all requests. Furthermore, mapping over an entire array before sorting and slicing is inefficient and allocates unnecessary memory for objects that will just be discarded by the slice operation.
**Action:** When dealing with data from `store.getAll()`, I will always create a shallow copy (e.g. `[...data]`) before sorting to avoid modifying the cached array. For large dataset transformations, I will defer `.map()` until after `.filter()`, `.sort()`, and `.slice()` are applied to process only the elements needed for output.
