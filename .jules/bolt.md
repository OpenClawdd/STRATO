## 2026-06-03 - Defer Map Operations on Large Datasets\n**Learning:** When transforming large dataset arrays (like in global leaderboards from `store.getAll()`), calling `.map()` before filtering or sorting creates O(N) short-lived garbage object allocations.\n**Action:** Always create a shallow copy (`[...data]`), then apply `.filter()`, `.sort()`, and `.slice()` before finally applying `.map()` to reduce memory overhead.
