## 2024-05-24 - Bounded Insertion Sort for Leaderboards
**Learning:** Leaderboard endpoints (`/api/leaderboard` and `/api/leaderboard/:gameId`) were retrieving all entities from the data store and running multiple passes over large arrays (`.filter()`, `.map()`, and a full `.sort()`). This creates excessive GC pressure from intermediate array allocations and causes O(N log N) CPU spikes for sorting when only the "top N" elements are required.
**Action:** Implemented a bounded insertion sort utility (`getTopNByProperty`) in `src/utils/sort.js`. This reduces time complexity to O(N) and space complexity to O(1) for calculating the top N items, skipping costly full-array sorts and deferring object transformation (`.map()`) until only the final 25 items remain. Memory directives specify that numerical fallbacks like `|| 0` must be used during comparisons to handle missing fields cleanly.
