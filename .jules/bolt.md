## 2024-06-19 - Avoiding Chained Array Transformations on Large Data Stores
**Learning:** Found an anti-pattern in the codebase where retrieving top N elements from `store.getAll()` results involved chaining `.map()`, `.filter()`, and `.sort()` on arrays potentially containing thousands of objects. This allocates large intermediate arrays, incurs heavy GC pressure, and uses O(N log N) time for the sort when only the top 10-25 elements are needed.
**Action:** Created a reusable `getTopN` utility function in `src/utils/sort.js` that implements a bounded insertion sort (O(N) time, O(1) space relative to N) to extract the top N elements efficiently without full array allocations. Apply this utility across the codebase wherever "top N" leaderboards, analytics, or stats are computed from large datasets.
