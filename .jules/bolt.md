## 2024-06-14 - Bounded Insertion Sort for Top-N Elements
**Learning:** Using `Array.prototype.sort()` to find the "top N" items from a very large dataset retrieved from the in-memory store (e.g. `store.getAll("users")`) introduces an O(N log N) time complexity bottleneck. Furthermore, chaining `.filter()`, `.map()`, and `.sort()` on large arrays spikes CPU usage and creates numerous short-lived objects that pressure the garbage collector during concurrent backend requests. A bounded insertion sort approach runs in O(N) time and O(1) space, avoiding large memory allocations and sorting entire collections.
**Action:** Created `src/utils/sort.js` with a `topN` function implementing bounded insertion sort. Refactored `src/routes/leaderboard.js`, `src/routes/admin.js`, and `src/routes/notifications.js` to compute global analytics and leaderboards using `topN` and consolidated single-pass loops.
