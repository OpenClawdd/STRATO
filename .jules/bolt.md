## 2024-06-20 - In-Memory Datastore Array Mutations
**Learning:** Arrays returned by `store.getAll()` are direct references to the in-memory cache. Because the custom datastore loads entire collections into memory, using `.sort()` directly on the returned array mutates the global cache, leading to data corruption across the application. Furthermore, calling `.map()` or `.filter()` on these large arrays before sorting causes unnecessary CPU spikes and short-lived object allocations.
**Action:** When working with large collections from `store.getAll()`, avoid chaining `.filter()`, `.sort()`, and `.map()`. Instead, use a bounded insertion sort (O(N) time, O(1) space) via a reusable utility function like `getTopN` to extract the required elements in a single pass before applying any transformations. Always provide fallbacks for `undefined` numeric properties during comparisons.
